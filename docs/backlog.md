以下均非当前交付阻断，不自动执行。排序以真实失败、复用价值和成本为依据；没有触发条件时保留，不为了填满流程开发。

| ID / 优先级 | 范围 | 触发条件 | 最小后续工作与验收 |
| --- | --- | --- | --- |
| GOV-01 / P1 | skill 管理 | 发生第一次外部契约破坏性升级 | 用旧输入做迁移/回退演练；证明消费者无法误用新字段 |
| GOV-02 / P2 | skill 管理 | 需要跨 repo 分发 | 打包完整依赖闭包、校验同名冲突、用户确认安装位置；不复制成多个可维护源 |
| GOV-03 / P2 | skill 管理 | 已出现真实误路由 | 新增一个最小对照 case，修正 description；不盲目扩张全套评测 |
| GOV-04 / P2 | 验证器 | 需要复杂 YAML 元数据或自动 CI | 采用明确依赖的 YAML/Schema 校验，保留无网络 smoke；验证真实错误能被拒绝 |
| WS-01 / P1 | 工作区 | 第一组真实跨模块并行任务 | 用该 repo 的本地基线演练冲突、端口隔离、依赖交接；保留两个恢复点 |

| PRD-02 / P2 | OpenSpec | 用户确认使用某个 CLI 版本 | 固定工具版本，运行离线/本地兼容性检查；不静默初始化现有业务 repo |
| PROD-01 / P2 | 产品评审 | 真实 PRD 的验收歧义导致返工 | 补一个失败/恢复或产品指标反例，评审输出含证据与最小补救 |
| TECH-01 / P2 | 技术评审 | 面临数据库/API/权限边界变更 | 增加该类 ADR 样例及受影响消费者；无事实不扩成全面架构重构 |
| TEST-01 / P1 | 测试管理 | 接入真实仓库测试命令 | 建 AC→case→层级的增量执行映射，报告精确 head/环境/未测理由 |
| TEST-02 / P2 | 测试管理 | 有 flaky 证据或多环境问题 | 增加隔离/重试分类和稳定性证据，不通过无限重跑抹平失败 |
| FLOW-01 / P1 | 单流水线 | 真实 feature 要节点自动执行 | 接入一个受授权的本地实现 handler，保留人工审批与失败停止；实测一次端到端 |
| FLOW-02 / P2 | 单流水线 | 确需 Google ADK 或其他运行时 | 按官方版本做薄适配，复用同一契约/测试，不另写一套业务状态机 |
| FLOW-03 / P2 | 多流水线 | 首批真实候选需要集成 | 接入只读 Git 状态验证及有授权的合并执行，测试 head 变化使证据失效 |
| FLOW-04 / P2 | 多流水线 | 人工交接已无法满足并发量 | 增加持久化状态/锁/恢复，不在首版引入常驻调度平台 |
| VID-01 / P1 | 导演学习 | 第一支具体广告练习 | 从已有卡选择方法，做小规模拍摄/分镜练习并附复盘；不假装已验证提升效果 |
| VID-02 / P2 | 导演知识库 | 新主题或来源变更 | 每次最多 6 页面，补齐声画节奏/表演指导/产品运动等缺口；新卡需独立来源与适用边界 |
| VID-03 / P2 | 导演知识库 | 出现失效链接/相互冲突来源 | 更新来源状态，保留历史与冲突解释；不删除仍有价值的旧卡 |

每次只认领能独立验收的一项；新增事项写出具体失败证据或使用需求。其余内部措辞、工具偏好、模板美化不阻塞当前闭环。
