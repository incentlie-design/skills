# 从人物正典到可引用定义

设计三类产物时使用这份字段与判断指南；只展开当前人物/服装实际需要的内容，不创建完整应用 schema。

## 1. 引用与事实归属

每个外部依据记录 `ref`（路径/章节/实体）、已知 `revision`、用途与归属：`canon_fact`、`research_fact`、`user_decision`、`proposed` 或 `unknown`。没有版本写 `unknown/provisional`；没有读到的来源不冒充已核验。来源冲突保留双方，若影响脸、年龄或服饰身份，停止该选择并给出需要决策的最小问题。

身份选择记录至少有 `character_id`、`asset_id`、`revision`、`ref`、`selection_basis`、`allowed_scope`、已有状态证据。校验的是用户实际选定的版本，不是文件排序；有实际文件且本轮读取过才记录算出的 digest，没有就说明未核验。不把设计 revision 混作媒体生成记录。新 ID 属 `proposed`，同一人的身份资产与衣服资产分开编号，但衣服仍引用同一个 `character_id`。

没有图片但有完整文字定义时可以 `design-ready`，同时说明图像身份一致性未测。只有图片文件名、没有可读内容，不能描述脸或决定“看起来更合适”。

## 2. character-visual-bible：形、年龄和材质

把正典中每个视觉约束对应到具体表达，补充项单列为提案：

| 层 | 怎么设计 | 不应混入 |
| --- | --- | --- |
| 人类身份结构 | 脸长宽与下颌、眉眼/鼻/口的相对结构、发际/头发轮廓、身高体量与比例、永久标记的位置 | 只写“英俊/年老”；把新装当新脸 |
| 年龄与长期暴露 | 以年龄阶段、职业/生活经历为依据组合发色、皮肤弹性/细纹、眼周及手部线索；晒感用露出与遮蔽部位的差异表达 | 把民族标签当肤色/晒感证据；任意添病态、伤痕或更老年龄 |
| 风格可表达的皮肤 | 写实可写可见但不过锐的毛孔、非均匀色素、低对比旧疤；水粉/卡通用色块、边缘、有限线条表达同样年龄线索 | 对所有媒介要求毛孔、统一磨皮、画死的皱纹或自动添加 glamour 禁令 |
| 临时表演与状态 | 表情纹随眉眼口运动，汗油/湿润随活动环境，新伤区别于已愈合疤；注明允许程度与退出事件 | 把一次皱眉永久烙在脸上；以疲劳任意改年龄/五官 |

非人类改用相应身体拓扑、比例、羽/鳞/毛等表面材质、特征及永久标记；群体定义成员范围、共同轮廓与允许差异。实体类型来自正典，不由视觉设计擅自人形化。

对本次易混淆的角色，比较至少一个不靠服饰的稳定身份线索，再按使用尺度选线索：远景看体型/发型/服装轮廓，中景看脸型与层次，近景看永久标记与皮肤。远景无需显示细小毛孔或疤；不为验证身份强行把背影改为正脸。正典刻意相似时，记录这一限制及可用识别线索，不擅改正典来制造区别。

## 3. wardrobe-variants：可穿、可变、可延续

先选择一套有理由的基础系统；若重要取舍未定才列少量备选，不默认穷举服装库。每个服饰资产写：

- **用途与依据**：人物/身份 revision、社会身份与实际活动、已知弧线阶段；地域/时代/阶层的具体来源，或用户的架空/风格决定。史料支持的结构与创作装饰分开，混用材质/时代时说明适配理由；无证据不使用“正宗/历史准确”。
- **构造**：肩/腰/下摆轮廓、内外层顺序、连接和拆卸点、面料厚薄与重量、磨损；配件的主人和身体附着处。描述材质在项目画风中的软硬、垂坠与反光，不自行重定项目灯光。
- **识别与动作**：主/辅色、纹样所在位置和尺度；远景轮廓、中景层次、近景细节。服装需支持该人物活动，指出妨碍抬臂、步幅或道具操作的部分；不能用身体增高变宽去补衣服效果。
- **变体**：稳定 `wardrobe_id`、`variant_id`（新建时 `proposed`）、关联人物、触发事件/用途、保留与替换的层/附件。变体仍引用原身份，若只改变湿污不额外制造新身份资产。
- **状态转移**：进入事件 → 改变项 → 残留 → 解除事件/条件，带可逆性。没有事件依据时保持前态或标未知；不猜下一场已清洗、痊愈或取回物件。

例如“淋雨后进入室内”只改变环境，并不解除湿衣；需要烘干/更衣或可支持干燥的明确经过，才允许该状态结束。这是连续性推理示例，不是所有项目都要有雨或换装。

服饰参考只允许迁移获准的轮廓、层次、材质或附件；模特脸、身形、姿势、凝视和背景不随服装迁移。需要参考视图时按缺口提出侧面/背面/动作或材质视图，不强制生成全套。

## 4. identity-prompt：可组合而不抢镜头所有权

每个人物提示词保留以下独立层，使用者可以替换状态而不重写身份：

1. `identity_binding`：人物/身份资产及精确选中 revision、正典/风格 refs、选中依据。
2. `invariants`：已定结构、年龄阶段、表面材质、永久特征；创作补充仍标提案，不能混入已定正典。
3. `style_binding`：当前风格中与该人物有关的表达限制；不新建世界风格。
4. `wardrobe_binding`：人物 ID + 服饰/变体 ID + revision，注明谁选择场景用装。
5. `variable_state`：允许的表情、视向/朝向、姿态、衣物状态；仅给已知事件约束，镜头位置与构图留给分镜/摄影。
6. `reference_policy`：每份参考的用途、`allowed_scope`、不得迁移项；若无媒体参考，明确当前只有文字定义。
7. `forbidden_drift`：违反正典、版本、年龄、皮肤风格或服饰结构的具体错误；避免堆砌不适用于本项目的通用负面词。

交接前检查：蓝本的不变量没有在服饰或 prompt 中被改写；提示词没有读取未选候选；事件残留仍在；新 ID 和新增特征是提案；允许侧/背面不代表允许换脸。未生成媒体，不能评“同脸通过”“皮肤自然”或“历史准确”；只报告文本范围内的证据。

## 方法来源与删减

方法抽取自旧源 `series-character-visual-development`（身份分层、实体分支）、`series-costume-visual-design`（构造、尺度与事件变体）、`knowledge/visual/continuity-and-reference-governance.md`（选中版本、用途隔离）、`knowledge/visual/human-material-lighting.md`（年龄与材质）；辅以 `narrated-drama-assets/references/asset-contract.md` 的定义/产出分离。它们是整理来源，不是运行依赖，来源版本与读取记录保存在本候选报告。

未迁入旧应用的 compiler、校验器、强制 Registry snapshot、身份锁和 working 指针；未迁入菲律宾/土著、v020、9:16 或特定光色的项目预设。这里的年龄、皮肤与服饰方法由输入项目风格选择适用强度。
