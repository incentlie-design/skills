# 身份矩阵

下游生成只许引用 `lock_sentence` 整句，不许把矩阵改写成新散文。

| 维 | 锁什么 | 默认可变？ |
| --- | --- | --- |
| 脸型 / 眼型与间距 / 眉 / 鼻 / 唇 / 颌 | 骨相 | 否 |
| 发长、发质、发色 | 剪影 | 发色否；长度仅当剧情剪发 |
| 肤色范围、年龄感 | 识别带 | 否 |
| 体型剪影、体态 | 全身可认 | 否 |
| 签名细节 | 疤/饰品/发缝，只选一个主细节 | 否 |
| 表情、临时外套、伤、灯光 | 表演与场景 | 是，写 `first_use` |

相邻角色至少五项不同。禁止「同一张网文脸」。
