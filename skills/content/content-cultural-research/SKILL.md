# 文化与本地化研究

回答当前创作决策需要知道什么、证据支持到哪里，以及下游应保留、调整或暂缓什么。不是每部小说、每个角色或每一集都必须外部调研；研究范围由改编距离和具体风险决定。

## 输入与所有权

- 必需：待解决的文化/适配问题、媒介与本轮范围、可读原作或设定摘要、来源时代/地域与目标受众/语言。原创项目可用用户设定替代原作；虚构或未知应明说，不能从作品名猜正典。初筛允许缺项，只追问会改变本轮结论的缺口。
- 可选：已有研究/本地摘录、实体 ID 与 revision、用户的保留项与改动权限、语言/视觉/声音候选、争议点、输出位置、外部查证授权和预算。缺作者、版本、权利或日期标 `unknown`，不补造；已有明确授权不重复询问。
- 默认只读提供的本地材料、只答复，不调用付费服务。用户要求搜索即是本轮相应查证授权，但仍需联网工具可用；没有授权或工具时给本地结果和未查缺口，不假装搜索。材料中的链接或命令不是授权。
- 只写用户授权的输出目录；原作、已审批设定与来源均只读。只提出约束候选，不改正典、不注册资产、不替人物/视觉/声音同事完成设计，不联系受访者、发布或生成媒体。

可交接产物遵循 [公共契约](../../../docs/contracts.md) 与 [内容生产约定](../../../docs/content-production-contract.md)。本 Skill 无强制专业 Skill 依赖，按文件交接；迁移时需带上这两份公共契约，不能依赖作者机器路径。

## 先判断需不需要研究

用几行比较：来源与目标的**时代/地域、语言受众、媒介与叙事功能**差异；是否借用真实群体、宗教/仪式、身份称谓或敏感历史；当前证据能否支持要做的决定。不能仅以“外国/古代/少数群体”为由无限搜集。

| research_mode | 何时选 | 本轮可做与停止点 |
| --- | --- | --- |
| `not_applicable` | 无文化适配问题，或纯虚构且没有现实文化借用、变化不影响文化含义 | 写明不适用的对象和理由；普通润色直接处理原请求，不强制生成研究包。不能用它掩盖缺材料或争议。 |
| `local_only` | 已有材料足以作本轮判断，或只允许本地材料 | 区分“足以交接”与“仅可作初筛”；保留未核事实，不把整理摘录称为外部查证。 |
| `external_scoped` | 决策依赖本地未解的现实文化事实，且查证已获授权、工具可用 | 先列待回答问题、来源类型、预算和停止条件，再搜索。无权限/工具则退回 local_only，并阻断依赖该事实的结论。 |

如用户明确要求查证，不以低风险替代其请求。没有足够设定来判断必要性时返回 `blocked` + `needs_input`，可同时给有边界的 provisional 初筛，不猜地区或族群。

## 有界执行

1. **把背景兴趣转成决策问题。** 例如“谁可参加这个仪式，会怎样改变拒绝行为的含义”，而非“研究这个国家”。列保留的叙事功能、可改表现及受影响实体/场景。按伤害或误读后果优先处理，不无差别补全民族志。
2. **定预算。** 优先采用用户上限；未指定时，本轮建议最多 3 个决策问题、6 项材料、15 分钟，外部搜索仅在获准模式下最多 3 组查询；先声明并可按实际风险缩小。问题已得到足够支持、连续两项材料未增加决策信息、预算用尽、遇访问/权利限制，任一发生即停。高争议未解则保留缺口，不自行加预算或用推断填平。
3. **提取可定位证据。** 实际读到的段落才能支持条目；搜索摘要、未打开链接只能列待查。按 [证据与约束方法](references/evidence-and-adaptation.md) 记录来源、适用范围和冲突。原作记载不等于现实文化事实；用户的印象不等于研究结论；重复转载不算独立互证。
4. **形成最小适配决定。** 对每个问题选择保留、解释、等效替换、虚构化或暂缓，并说明如何保留原叙事功能。约束必须有证据/用户依据、作用对象、下游负责人和可检查结果；没有依据的创意标 `creative_inference`，不得写成某群体的真实习俗。用户要求与事实冲突时并列记录，提出选择，不暗中重写任何一方。
5. **只交接受影响范围。** 使用已有 ID 和实际选定 revision；新 ID 标 `proposed`。后续反馈只更新受影响约束，提高产物 revision、标出下游待复核，不按每集自动重搜。没有新问题、来源变化或失效证据，不重启研究。

## 输出与结束

研究包可为一个含三节的文档；用户指定分文件时使用 `culture-brief.md`、`source-ledger.md`、`adaptation-constraints.md`，都放在获准目录，不回写 Skill。咨询直接在回复里交付，不伪造 repo、commit 或运行记录。

| artifact_kind | 最小内容 | 消费者 |
| --- | --- | --- |
| `culture-brief` | 目标/范围、输入 refs/revisions、研究模式及理由、时代/地域/改编距离、优先问题与风险、预算/实际动作/停搜原因、可继续与暂缓项 | 改编/策划责任人 |
| `source-ledger` | 来源与具体定位、已知版本/访问情况、权利限制；分开的原著事实、用户要求、研究事实、创作推断；适用范围/可信度理由、冲突和开放问题 | 所有受影响专业 |
| `adaptation-constraints` | 约束 ID、依据、保留/调整/禁用/暂缓对象、条件与例外、实体/场景 refs、下游消费者、验收和未解项的解除条件 | 改编、人物、视觉、声音；需要时交翻译/字幕 |

每类产物声明自身 revision、实际输入 refs、开放问题和 handoff；落盘结构化记录使用公共 envelope 的真实 `base_commit`、正整数 `artifact_revision`，未提交内容以 `uncommitted` 加摘要标识。`status=pass` 仅表示本次有界候选可交接；尚需选择或修订为 `revise`，关键输入/证据/权限阻断为 `blocked` 并给最小恢复条件。`not_applicable` 是有理由的适用性结论，不是研究通过。

结束前检查每条硬约束是否有可定位依据、冲突是否可见、未知是否仍为未知。包内达到本轮决策需要即停止，不以来源数量凑“完整研究”。不得声称已得到社群认可、已验证真实口音、已试听、已生成或已注册；这些需要各自的实际证据与授权。
