# 证据如何变成适配约束

有实际来源需比较、相反说法，或准备交给语言/视觉/声音专业时读。本方法不要求复制来源全文，也不要求应用 Registry、receipt、CAS 或旧版私有 JSON schema。

## 1. 来源与主张分开

先给来源 `source_id`，再给会影响本轮决定的主张 `claim_id`；不要把一份来源的整体声望移给其中每个说法。

来源最少记录：`source_id`、路径或 URL + 页/节/实体定位、作者/发布者、已知版本或日期、所述时代/地域/人群、材料类型、实际访问方式/日期、权利和引用限制。无法获知的字段写 `unknown`；本地摘录记 `local_excerpt`，实际打开网页才记 `external_read`。输入是 fixture 时保留标识，不能对外推为现实证据。未读链接留在待查列表，不进入支持主张的来源集。

主张记录：`claim_id`、窄到能判断真假的陈述、`kind`、`source_refs`、适用范围、`evidence_state`（supported/provisional/disputed/unknown）及可信度理由。未知时不造数值信心；“未找到证据”不等于“不存在”。

| kind | 表示什么 | 不能推成什么 |
| --- | --- | --- |
| `source_fact` / 原著事实 | 指定原作/设定版本确实如此写，绑定章节/实体 | 现实历史或整个民族的普遍习俗 |
| `user_requirement` / 用户要求 | 用户明确的目标、保留项或取舍；印象另标 unverified | 已核实的文化常识或许可 |
| `research_fact` / 研究事实 | 实际读到的资料支持什么陈述；暂未核的摘录只能 provisional | 跨地域/跨时代/所有人的统一规则 |
| `creative_inference` / 创作推断 | 基于前述依据提出的解释、等效处理或设计选择 | 原著原文、研究事实或已经批准的决定 |

优先选能回答该问题的原始档案、物件记录、语言资料、群体成员记述或研究者的直接材料；再用有方法与出处的研究补充解释。评估是否同一时期/地域/身份、记录用途、翻译损失与传播链。官方机构不自动覆盖成员经验；单个成员也不代表全体。旅游文案、模型生成内容和拼贴图库不能独立证明传统真实性。

对会导致污名、禁忌误用或关键情节错误的主张，尽量找到独立来源或相关社群的一手观点；找不到便缩小结论或暂缓。需要专业人员/社群咨询时只列待办，不替用户联系。权利不明时保留必要出处与简短释义，不把研究访问许可当作复制图像、声音或仪式的生产许可。

## 2. 冲突不能靠投票消失

每组冲突记 `conflict_id`、双方 claim/source refs、真正不一致的点、各自时间/地域/语境、对当前决定的影响、处理与再开条件。

1. 先检查是否说的是不同场合、群体、时代或同词异义。差异能由材料解释时分别限定范围，写出理由。
2. 同一范围仍相反时标 `unresolved`；不能用“较新”“机构更大”“转载更多”直接获胜。列需要补的原页、版本或独立记录。
3. 对阻断项暂停相关断言/设计；其它不依赖冲突的部分照常交接。可提出避开争议的创作候选，但要保留原冲突，不把候选当作解决证据。

示例方法：两条材料对“谁可参加某仪式”相反时，先核场合和成员身份；若仍无法判断，暂缓“所有来客都必须参加”的世界规则。人物拒绝行为可保留为原作事实，拒绝的普遍文化含义仍待查。此例是判断方法，不是任何文化的事实。

## 3. 约束应能交给具体专业执行

每条记录 `constraint_id`、`decision`（keep/explain/substitute/fictionalize/defer）、依据的 claim/user refs、叙事功能、适用实体/场景及来源 revision、可改/不可改/例外、`consumer`、`acceptance`、开放问题。未解项加 owner（未知则待分配）、阻断范围、解除所需输入；作者不能假装已被授予批准权。

先保留角色欲望、权力关系和选择代价，再处理文化形式。按当前问题选必要维度，不强迫把下表全部填满：

| 维度 | 具体检查 | 交接边界 |
| --- | --- | --- |
| 称谓与语域 | 谁对谁说、身份/亲疏/权力、正式与私下是否不同；翻译是否改变冒犯程度 | 可提功能对等策略；缺术语证据就交待查词表，不编发音或 IPA |
| 语言切换与口音 | 何时切换、对谁可懂、人物如何被区分；是否把一种口音等同智力/道德 | 提语言身份与可懂度要求；不得默认美英口音或强制每个角色带口音，声音验证留给有实际材料的专业 |
| 仪式与关系 | 谁有资格/义务参与、拒绝意味着什么、权力和同意是否改变 | 原作的个体行为与真实群体规范分开；禁忌、宗教或身份误用证据不足就 defer |
| 物质与视觉 | 物件用途、时代与地点、制作材料、服饰身份、符号是否跨群体混用 | 给已支持的材料/功能和待查项，不用“异域/部落风”等标签替代具体设计 |
| 音乐与环境声 | 声音的场景用途、表演主体、仪式/日常差别、录音与使用权 | 不把有某件乐器推成整区固定配乐，不宣称已经听辨或完成混音 |
| 字幕/广告表达 | 受众怎样理解信息、解释与剧透/节奏的取舍、广告是否暗示真实群体背书 | 交语义和待核表达；实际 timing、素材生产与发布审核属于下游 |

验收写成可观察结果，例如“受影响场景不能把一名角色的做法说成整个群体通则”“候选称谓保留上下级关系且未引入未经支持的族名”；不要用“更地道”“尊重文化”代替检查条件。明确哪些是用户要求、证据限制、作者建议，避免建议无意升级成硬禁令。

只交当前范围所需的资料和约束。地域、族群、年代、画幅、声速、voice ID 都不是本方法默认值；项目预设只能来自当前输入，不搬历史项目设定。
