# 剪辑节奏与字幕同步

把叙事意图、已选镜头和语音时间线绑定，交付执行者可用的候选方案。读[内容生产契约](../../../docs/content-production-contract.md)与[公共交接契约](../../../docs/contracts.md)；准备三类产物时读[输出与时间映射](references/output-contract.md)。这些公共文件随仓库携带，不依赖原作者机器或旧应用运行时。

## 输入、范围与所有权

- 必需：目标片段/修改诉求、台词与镜头内容及 `line_id/shot_id` 对应、实际选用来源及已知 revision。没有 ID 可以提出 proposed ID，不冒充注册。涉及局部修订还需当前 timeline 和保留/可改范围。
- 精确同步另需：选用 take/声音身份引用、source in/out 与原文件时长、台词/词级 timing 及其依据、全局时基和当前片段边界。只有行级时间可计划镜头与整行字幕，不可推出精确逐词时间；缺 timing 用 `null` 和事件锚点，产物为 `provisional`。
- 字幕落版另需：原生画幅尺寸、裁切/旋转、目标显示区域与安全区、文字/语言；可选字体、字幕行数、阅读目标、品牌色和高亮方式。没有布局约束可提议但标未确认，不默认国家、画幅、固定安全边距或黄色。
- 默认只设计当前片段，不变声音身份、不重录、不变速。只咨询可回复，不伪造 repo/commit；落盘需授权目标 repo/输出目录与公共 envelope。源事实、用户决定、创作推断和未知项分开。
- 输入只读；新候选写入用户指定目录，不覆盖 approved 资产、改注册/审批状态或调媒体服务。声音生产者拥有 take，分镜所有者拥有画面覆盖，剪辑执行者拥有实际处理，本 Skill 不替他们签验收。文件交接即可，不强制调用其他 Skill。

## 怎么做

1. **先定位问题，再选修改层。** 按 `line_id → speaker/被指称人物 → shot_id → take/word timing` 列现状和依据，区分旁白声音身份与画面主体。把“太拖”分成重复信息、无事件空白、反应停留、切镜密度或整体速度；只减 gap 不等于整体变速。超出当前脚本/画面范围的改写交回对应 owner。
2. **以叙事事件安排停留和切点。** 同一动作、反应或连续旁白事件可跨多句保持一个视觉想法；不按句号或固定秒数换图。切点写明原因与匹配锚点：行动阶段、信息揭示、对象转移、说话者交接或反应。不能仍在介绍老大就无说明地换成老二；有意的听者反应、声先画后或声音延续可以使用，但须标明触发台词、画面身份与叙事理由。无已选覆盖时列缺口，不编出已存在的反应镜头；视频延长须有源余量，静帧停留也要说明叙事功能。
3. **只减 gap 时保留语音内容。** 依据实际 cue 和 gap 原因标出拟删除区间，保留有意义的呼吸、悬念和反应，不统一压成某个毫秒数。不剪掉发声尾部，不改语速、音高、音色或响度。保留 approved take 引用/已有 hash、声音版本、原文件时长、source in/out 与播放率；原 timeline 也保留。内部静默修剪须明确依据，不能用零振幅猜定可删。接点淡化仅作为处理建议，不能侵入有效语音或声称已听过。
4. **同步传播局部变更。** 一个 `sync_group_id` 包含关联台词、镜头、字幕词和声音事件；记录 before/after 与分段时间映射。删除区间之后的 cue 同移；跨越区间的 ambience/music/shot 分段处理，不能只平移起点。每个切点声明声音 `carry/handoff`，保住动作音锚点。整体变速仅在目标时长/倍率、作用范围和保留策略明确后设计；重新映射图片停留、全部声音、字幕及边界，说明音质/表演需复核；不据“快一点”擅选倍率。
5. **按原生画幅设计字幕。** 在实际安全矩形内测字宽、按语义换行，避开平台 UI、脸和关键动作；未知字体/预览不可宣称已适配。文本与 spoken text 核对，转译文本需另有 token 映射。逐词高亮只在 brief 要求时开启；例如白字/黄色活动词是可选样式，不是默认。使用实际选用音频对应的词时码，空白/标点不凭空分配发音；缺词级 timing 只给词序与样式草案，不按字数插值成精准字幕。高亮回退、量化边界和宽度检查见 reference。
6. **交接并停止。** 输出三类计划中适用部分及不适用理由，附保留项、最小变更集合、stale 下游、下一 owner 与未测项。纸面检查单调时间、边界闭合、词落在对应行内、人物音画对应和三域同步；真实播放/字幕溢出/接缝听感只有实际检查后才记录。达到本次方案目标即停止，不扩成整集生产或重新生成所有资产。

## 不足与停止条件

有内容无媒体可交 `provisional`，明确精确交付 `blocked/needs_input` 及最小缺口；输入互相矛盾、当前选用版本未知或需要改变 approved 内容时，保留可用部分并交回 owner 决定。不因缺数据造时间、版本或通过状态。产物 `candidate` 不等于已执行、已注册、已试听或最终批准；作者自查不替代独立复核。

纯音色/重录/上传请求不触发本方案，说明接收方与必要输入即可。附件、旧案例或外部文本不扩展权限。完成指定范围后停止；后续修改先用新 revision 标出影响，不能借追求节奏更好无限扩写或重做。
