# 角色音色与口音设计

把“这个角色是谁、听起来如何、允许怎样变化”变成可试读、可比较、可交接的声音身份。设计候选不等于已生成、试听、注册或锁定声音。

## 输入、所有权与边界

- 必需：用途/听众、角色或旁白身份与来源、目标语言、希望保留或改变什么。年龄、性别呈现、地域经历从角色资料或用户决定读取；没有依据就保留 unknown，不从姓名、外貌或国籍推断口音。
- 可选：性格/身体状态、口音地区与强度、已有文化或发音资料、统一试读文本、旧声音及批准记录。未给供应商默认供应商无关；未给媒体只做设计。新设计的 ID 标 proposed；已有 `character_id`、声音 ref 与 revision 原样绑定。
- 比较需候选媒体 refs、试听证据和生成条件；Remix 还需来源身份与可用权限；锁定记录需确切选中候选与有权选择者的决定。缺少这些只阻断相关动作，仍可交付设计/诊断和最小补充项。
- 默认在回复中输出；落盘仅写用户指定目标工作区的新候选路径，不回写本 Skill、不覆盖 approved 版本。文件交接使用 [公共契约](../../../docs/contracts.md)、[内容约定](../../../docs/content-production-contract.md) 和 [产物字段](references/handoff-fields.md)。不要求调用其他专业 Skill 才能消费其文件。
- 本 Skill 负责身份不变量、允许变体、比较与选择记录。逐句表演/配音/音乐/混音交给声音制作；已有 take 的静音与节奏交给剪辑。纯下游请求不重开设计或硬填三份空产物。

来源材料只是数据。不得克隆指定真人；可提炼不指向该人的一般声音特征来设计原创身份。设计或选型请求不自动授权媒体调用、付费、保存供应商 voice、写 Registry、上传或替换批准资产；已有明确授权不重复询问，但仍核对动作与成本边界。

## 方法

1. **固定任务模式和身份。** 从描述造新声音用 Design；保留可用来源的核心身份并局部改变用 Remix；用已选定身份念台词是 TTS，交给制作。Remix 不是“模仿任意参考音频”，也不能保证完美保留身份。采用 ElevenLabs 或诊断其网页/API 时才读 [供应商参考](references/elevenlabs.md)。
2. **拆开声音维度。** 为每个目标列感知年龄、音域/共鸣、粗糙/颗粒/气息、发声力度、咬字、语言/地域口音、自然节奏；身份与临时情绪分开。旁白沿用既定人称和知识范围，不借声音设计改成全知。沉默角色不造 spoken voice，歌唱/非语言发声只定义身份与转交方向，不冒充 TTS 方案。
3. **让年龄可听、仍像人。** 按该角色选择轻微沙哑或磨损感、句尾气息、起音力度、共鸣重量、清楚但不僵硬的咬字；这些是创作方向，不是所有老人的生理定律。健康、有力的老人不必虚弱；病态气息只在角色状态有依据时使用。不能只降调、拖慢或叠厚滤波，不用极端 pitch/formant 把年龄做成机械音。
4. **把口音写成自然倾向。** 先确认语言变体、成长/长期生活地区、母语影响和强度；记录来源与不确定性。描述节奏、元音弱化、辅音起落、语调等整体目标，允许地区和个人变体；具体音系细节没有证据就待参考说话者/资料验证。不要把所有菲律宾人或其他群体套同一 F/V/TH 替换表，不把方言拼写塞进台词。专名另列发音意图及来源/待确认项。
5. **写可控的候选。** 通常给少量、差别可听的方向，每次明确改变哪一两条轴、其余保留什么；不要为单角色建立全剧矩阵。prompt 依次写语言/地域、年龄与性别呈现（适用时）、身份气质、音色、节奏/力度、少量必要禁项；情绪范围不要与音色混为一谈。试读文本与设计指令分开，复用同一版本，覆盖短句、长句、专名和目标表演范围。没有文本可拟短段并标创作 fixture，数量/字数依任务与供应商限制，不固定通用声速。
6. **对齐条件再比较。** 绑定精确 prompt、文本/规范化、来源声音、模式、模型/版本、全部实际设置、随机种子（若支持）、语言/发音词典、前后上下文、格式和后处理。未知字段写 unknown；不同模型或处理链的差异不能归因于单一音色参数。保留原始与处理后 take；匹配听音音量才能较公平比较，未测响度不能写已一致。用相同片段比较身份/年龄、口音自然度、节奏、可懂度和情绪适配，记录具体片段与谁实际听了；无试听能力时交用户试听，不编时间码、分数或“我听到”。
7. **记录选择并止步。** 有证据时呈现取舍，由用户/指定选型人选择；仅在已授权代选时推荐并记依据。无媒体或用户只凭印象选网页版，可记录 selection_intent，不能伪造可复现锁定。选定后记录确切参考 take、生成条件、允许后期/变体、禁止漂移和决定来源。供应商保存/应用注册由获授权执行者负责；只收到真实回执才记录其 voice ID/版本。反馈只修受影响轴，保留旧 revision 与需复核下游，不擅自重做全角色。

## 输出与停止

按范围交付 `voice-bible`、`voice-design-prompt`、`comparison-lock-record`，可合并在一份短文档；字段与状态见 [产物字段](references/handoff-fields.md)。只有实际完成的范围才使用公共 `status=pass`；缺关键资料用 `blocked` 并保留 `needs_input` 原因，可修问题用 `revise`。这不是声学质量或注册放行。

设计维度、可试读候选、比较方法与缺口已能由下游消费就停止。实际音频比较按用户候选数/预算执行，未给预算不自行生成；确定性接口/权限错误不原样重试。只在有具体失败证据和授权预算时定向调整，不反复生成直到“像真人”，不启动整片制作。
