# 视觉决策方法

这是通用设计方法，不是旧 Drama 应用 schema。按当前工作读取相关小节；无需为了填写字段补造事实。

## 风格与材料

从一个实际选定的风格 ref 出发，把每项写成「规则—叙事作用—来源—允许变化—禁止漂移」。例如克制强调色应说明用在哪类信息上、哪些状态可变化，而不只列色号。跨媒介保留这些语义不变量；构图、画幅、渲染精度由目标媒介另定，不默认写实、胶片、9:16 或固定镜头。

至少覆盖当前任务相关的决策：

| 决策 | 怎么做 |
| --- | --- |
| 呈现与表面 | 选定写实/手绘/图形等呈现逻辑；说明边缘、纹理密度、磨损和反射服务何种可读性。已有风格不重选。 |
| 皮肤与服饰材料 | 读取选定角色/服饰定义，保留肤色和身份；决定光照下如何仍可辨认。写实项目才要求相应微纹理与汗油分布，不给所有材质统一塑料高光；其他画风沿用其抽象方式。服装款式/身份归人物视觉，本 Skill 只提供材料与环境适用性约束。 |
| 光色 | 主色、强调色、饱和度/明暗关系与情绪或信息变化绑定；明确环境反射可以影响表面到什么程度，不把全局染色当气氛。 |
| 奇幻机制 | 写触发条件、持续/退出条件、可见异常与仍保留的自然规则。允许自发光需明确世界依据及照亮周围的后果；反射性、银白色、神圣性都不自动等于发光。 |

**历史与文化适用性。** 只有要求真实地域/时代或引用具体文化时才做此判断。逐项登记 `claim → 地域/年代/使用者/用途 → source_ref+revision/页段 → 适配决定 → 置信与缺口`。检查材料、加工与染色方式、贸易可及性、气候和社会用途是否适用；“古代”“土著”“海岛”不能充当事实依据。混合时代要显式说明哪些是创作改编，不称完全考据。无来源或本轮不能研究时停在 `provisional`，将待证点交文化研究/项目责任人，不编文献。参考作品只能支持风格借鉴，不能自行证明历史事实。

## 地点与道具

**地点：从俯视关系到可见锚点。** 先用简短方位描述或邻接表定义出入口、分区、连接与障碍，再给关键距离/相对尺度；数字注明原文、用户给定或设计估计。不要把画面左/右当固定地理方向。多个地点只画任务涉及的连通关系；未知路段保留缺口，不能为凑地图重写地理。

每个地点卡包含：

- `location_id`、来源版本、风格 ref、用途；固定轮廓/地标/锚点、朝向、出入口、通路与尺度。
- 主表面材料及新旧/干湿基态；可用自然/实景光源与受遮挡条件。
- 不变量、允许时段/天气/布置变化、禁止元素；当前状态单列，可未知。

地标要可复认且互相有关系。例如「入口正北是门，树在入口西侧」比「有古树和门」更能防止空间漂移。只定义空间可供通行和物件可放置的约束，不替调度安排人物走位。

**道具：身份与状态分开。** 给一个推荐形态及其叙事用途；若有象征意义，注明是来源还是推断。记录轮廓、尺寸/相对人体尺度、材料、重量或可握性判断、接触/握持点、磨损方式；使远距靠轮廓、中距靠操作、近距靠关键细节可辨识，不因此决定镜头。

每个道具卡包含：

- `prop_id`、来源版本、风格 ref；不变量与允许变体。
- 已知 `holder/hand/contact/location/condition`，无输入即 unknown；放下后接触点应从手变为承托面，不能仍记为手持。
- 允许转换用「前态 → 触发/前提 → 后态」描述，例如开/关、完整/破损、干/湿。修复、消耗或魔法改变要有依据。当前发生了什么只由实际 beat/state 输入决定，不能把允许转换误记为已发生。

## 灯光与色彩变化

先列任务内的故事/信息变化，再设计连续光色段，避免每个画面重新发明风格。每段记录：

1. 实际 beat/时段/天气/location zone 引用；哪些是已知，哪些是提案。
2. 自然光、实景灯、火、水面/墙面反射或有依据的超自然光源；区分可见、可推断与新设计。说明主光、补光/反射和边缘光的实际来源，不能因画面好看给每个人加一圈光。
3. 方向、软硬/范围与衰减、明暗对比；脸、手/动作、道具、背景的关注层级。精确 lux/Kelvin/曝光档数只有实测输入才写成测量值。
4. 相关材料的不同反应：皮肤基色如何保留、织物如何散射/吸光、粗木与湿木如何不同、金属如何出现有限反射、玻璃如何透出/反射光。仅写任务实际涉及的材料，别列空清单。
5. 主色/强调色关系、环境染色界限、雾尘等气氛的物理或世界依据、前后段连续性。没有天气依据时，雾雨只是未采用的提案，不能写成来源事实。

梦境或奇幻开始/结束时，通过实景光变化、曝光/色彩渐变或重复物件等建立可识别过渡，并保留至少一个现实锚点。若世界未规定发光，银树可先表达为浅色树皮/银色叶片对现有光的局部反射；具体材质仍须服从原文，不一律改成某种真实树种。

只交设计意图与受影响引用给摄影/分镜/剪辑。没有实拍或生成结果，就没有最终肤质、曝光、色准、可读性或成片质量通过的证据。
