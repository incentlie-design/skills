# Content Skill taxonomy

Ticket: https://github.com/incentlie-design/narrated-drama/issues/112

分类按**能力约束来源**，不按来源仓库。镜头语言即使从短剧经验抽取，仍属 content。

## Categories

| Category | 回答的制作问题 | R | Skills |
| --- | --- | --- | --- |
| story-adaptation | 原著如何变成十集 60–120s | R1 | content-adaptation-shortform |
| canon | 系列事实、知识、推断分界 | R1 R2 | content-story-bible-canon |
| character-narrative | 观众如何听出不同角色 | R2 R3 | content-character-development |
| character-visual | 观众如何认出同一张脸/同一套衣服 | R2 | content-character-visual-lock |
| episode-writing | 单集旁白/对白是否装得进时长 | R3 | content-episode-writing-narration |
| storyboard | 镜头顺序能否交给生成/合成 | R3 R4 | content-storyboard-shotlist |
| cinematography | 观众此刻该看什么 | R3 R4 | content-cinematography-shortform |
| blocking | 人在空间里怎么动 | R3 | content-scene-blocking |
| manga | 格与格之间读者补什么 | R3 | content-manga-panel-language |
| continuity | 跨集会不会穿帮 | R3 R6 | content-continuity-review |
| voice | 旁白与角色声线是否可辨 | R2 R4 | content-voice-narration-design |
| music | 配乐是否让路、十集是否同一家族 | R2 R4 | content-music-bed-design |
| ambience | 地点底噪/环境/拟音是否成立 | R2 R4 | content-ambience-foley |
| audio | 能不能听清、时长是否合格 | R4 R5 | content-audio-mix-probe |
| image-consistency | 生成图会不会换脸换衣 | R2 R4 | content-image-identity-consistency |
| editing | 60–120s 信息密度 | R4 R5 | content-editing-rhythm-60s |
| evaluation | 什么叫 PASS / 返工 / 放弃 | R1 R5 | content-evaluation-rubric |
| series-identity | 十集哪些必须相同 | R2 R6 | content-series-identity-lock |
| safety | 提示词、权利、凭据 | all | content-prompt-safety-provenance |
| production-plan | 谁写哪集、何时停 | R4 R6 | content-production-plan-shortform |

## Index categories (for sources, not Skills)

`story` `character` `visual-consistency` `cinematography` `directing` `editing` `storyboard` `image-gen` `voice` `music` `ambience` `audio` `manga-anime` `continuity` `production-planning` `evaluation` `safety` `meta-format`

`meta-format` 只解释 Skill 文件格式（如 anthropics/skills），不把它的业务技能当权威。
