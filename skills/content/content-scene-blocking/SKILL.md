# 场面调度与动作表演

把已有场景意图转成可读、可表演、能追踪前后状态的调度候选。负责人物空间、目光、动作因果和道具接触；剧本、人物身份、摄影参数、音色和最终执行各保留原所有者。

## 输入与交接

- 必需：范围内剧本/动作摘要及来源、人物与不可改变的事件顺序和结局。涉及道具须有数量、当前持有人/手别/位置；修改旧计划还须有确切旧版及入场状态。缺少会改变因果的输入，返回 `status: blocked, reason: needs_input` 和最小补充项，不凭经验恢复“昨日已批准”事实。
- 可选：人物关系/此刻目标、场地布局、进出通道、服装或行动限制、影视/舞台、既定视点/轴线、既有 shot/line/asset refs、排练反馈。新设计可提出有标记的空间安排；实际场地或机位未知，不宣称屏幕方向、视线遮挡或可行性已经确认。未要求精确时间时用事件先后与 cue，不估成实测毫秒。
- 默认仅回复。落盘需目标 repo、可写目录及公共运行信息；只写授权范围中的新候选，不覆盖已审批版本，不回写本 Skill、注册表或媒体资产。结构化交接遵循 [公共契约](../../../docs/contracts.md) 与 [内容交接约定](../../../docs/content-production-contract.md)。
- 输出为 `blocking-plan`、`action-state-map`、`reaction-cues` 三个逻辑产物，小场景可合在一份文件内。交给分镜/摄影负责人、舞台导演或舞监；相关 cue 交声音/剪辑。按任务读写文件交接，无强制专业 Skill 调用链。需要交接时读 [字段与检查方法](references/handoff-fields.md)。

## 工作方法

1. **固定事实与范围。** 沿用 `scene_id/character_id/location_id/prop_id/line_id/shot_id` 和实际选定版本，不靠同名或最高版本猜权威。新动作单元可提 `action_id`，标 `proposed`；未给版本记 `unknown/provisional`。分开列来源事实、用户决定、创作推断和未知，不给推断加“已确认”标签。局部调度不扩为全剧资产。
2. **先画空间关系。** 给人物入口/起点/终点、身体朝向、路线及遮挡点；固定世界坐标。影视另记既定视点下的屏幕左右、行动/视线轴；机位变化要重算，不用演员左右手替代屏幕左右。舞台记录观众方位、演员面向观众的固定舞台左右与上下场口，不把舞台左右随演员转身翻转。多面观众另记各区视线，不假定镜框式舞台。
3. **把动作拆成状态变化。** 每个因果单元按准备 → 接触/释放 → 结果组织，必要时再给恢复或退出。记录谁作用于谁/什么、用哪只手或身体部位、运动方向、接触点、前后状态。持续镜头或舞台表演可顺序承载多个单元；一张关键帧只选一个决定性动作，不能同时塞入落下、接住、转身三个时刻。
4. **逐根追踪道具。** 全场数量与当前可见数量分别记；出画不等于消失。每个状态给实例 ID、持有人、左/右/双手/无人、支撑或接触对象、空间位置、条件与可见性。交接时明确谁先接触、谁松手、最终归谁；共同接触是同一物的过渡，不复制道具。检查一只手是否同时被不相容动作占用，前一状态的终点必须接上下一状态的起点。
5. **分开说话、反应和注意力。** 对关键台词/沉默，给 speaker 一个可执行目的与动作动词（如安抚、催促、试探），再给身体/手势和眼神；有口型需求时注明嘴部是否可见。对听者独立记刺激源及 cue、可感知原因、视线目标、发现/判断/决定/余波中的阶段和可观察反应，不只写“更难过”。观众此刻应注意的事件另列。反应不能早于刺激；预判反应须绑定已感知的准备动作。人可回避目光，但须说明原因；不能因国王/旁白在说话，就让所有人看他。直视观众/镜头只在明确的表演约定下使用。
6. **走一遍因果再交接。** 从入场状态逐行追到出场：数量、手别、方向、接触、视线触发和结局是否一致；检查动作/反应在指定视点是否读得清，未知部分留给现场或画面复核。只提最小改动及保留项，标明受影响下游 refs/revisions；不通过改台词、添剧情或换道具身份来掩盖调度冲突。

## 完成与停止

- `pass` 仅表示请求范围的调度设计已交付、来源和状态可追踪；产物成熟度仍为 `provisional/design-ready`，不是独立评审、生成、排练、take 或安全认证通过。可用部分与待补部分并存时交 `revise` 并指明下一责任人。
- 缺关键来源、旧版相互冲突或无法连接入出状态时 `blocked`，返回精确缺口；不要补写故事结局。无关的纯剧情改写、摄影参数或音色设计，说明职责边界，不启动三份调度产物。
- 真实击打、跌落、火、水、高处或武器等危险表演只标风险与叙事效果，转合格现场专业人员；可给非接触、借位、剪辑等高层表达方向，不给攻击点、力度、危险跌倒步骤或安全批准。设计与模拟也不能冒充真实排练证据。
- 到约定场景/修改范围完成即停；一次自查后只修有证据的局部问题，不自行扩成整集生产，不调用媒体/付费接口、写 Registry、发布或安装。
