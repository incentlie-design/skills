# 从连续状态到最小修复

在存在跨集、知识边界、音画引用或阶段争议时，按相关行检查；不为补齐表格要求与本次目标无关的材料。这里只规定专业判断，不使用旧应用的 Registry/CAS/可信回执校验器。

## 状态链与知识链

每个相关实体记录：`先前状态及 ref → 解释事件及 scene/line → 本次观察及 shot → 预期后继状态`。事实、项目选择、推断与缺证据分栏表达；观察不一致先判断缺的是过渡证据还是已证实冲突。

| 维度 | 实际做法 | 何时形成发现 |
| --- | --- | --- |
| 正典与因果 | 比对本集目标、前集结果、角色关系/伤病/时间线；核对变化是否有来源事件或用户决定 | 改写已确定事实、恢复伤病或跳时却无解释；倒叙/梦境有标记时不因时间倒退自动判错 |
| 角色与旁白知识 | 为每项关键信息标出知情者、获得方式（目击/被告知/揭示）、获得 line/scene、首次使用点；旁白按项目授权视角单查 | 首次知情前精确说出/据此行动；限知旁白泄露其无从得知的信息。获准全知旁白、误猜和刻意不可靠叙述须按证据区分 |
| 身份与允许变体 | 比较 stable character_id、实际选定身份 ref 和永久特征；衣着、湿污、表情看本集允许范围 | 选中版本被旧候选替代，或永久特征无授权漂移；文稿设计不能被描述为已验证脸像 |
| 道具与动作 | 跟踪 prop_id、所有者、接触者、左右手、状态及位置，查转交/拾取/落下；比较相邻 shot 起止帧描述 | 同时被两人持有、无过渡换手、进出空间不可能等。明确获准省略的动作不强加补拍 |
| 空间与视线 | 从场景拓扑检查入口、屏幕方向、视线目标、前后动作接点；跨轴要有可读的重定位依据 | 计划内矛盾或媒体中已观察的误接；无成片时不声称最终轴线或动作匹配已通过 |
| 引用用途 | 核对参考来源允许传递身份、服装、道具或环境的哪些维度 | 把身份近景参考的姿态/构图强加所有镜头；远景身份依靠轮廓/服装/动作时，不强迫露近景正脸 |

## 音画覆盖链

按本次 read_set 建 `line_id + speaker → voice identity ref → shot_id → subtitle/edit ref` 映射。对白、旁白、画外音分别保留；不要求每句都有说话者露脸，也不把一个 line 跨多个 shot 自动算重复错误。

- 缺 line 覆盖、speaker 串人、voice ref 与选定身份不符、对白/表演指导混进字幕，定位到对应行和 revision；局部纠正映射而非改全体人物声音。
- 对白所说、可见动作、道具状态和镜头先后应相容；旁白不能为画面里不存在的结果提供虚假连续性。仅估计长度时只判断计划可行性，不声称逐词字幕或口型精确同步。
- 有媒体才写实际视听发现，并绑定具体文件/版本、shot/timecode、检查方式和覆盖量。查看静帧不能证明整段动作；文本推断不能证明口音/音色自然；实测响度/时长须有相应数据。
- 环境声/音效/音乐只在本 scope 需要时检查进入/退出和跨镜头衔接；明确不适用的音乐层不必补作曲。无法查看/播放的材料记 `not_run`，不要根据扩展名或生成成功回执写通过。

## 影响集合怎么收窄

每项建议至少列 `finding_id, changed_ref, affected_refs, action, reason, owner, recheck`。`action` 是建议（如改稿、重绑定、定向复核、保留），不是已执行动作。未知映射明确 `unknown` 并索取最小依赖清单。

| 变化 | 通常应追到的下游（须由实际引用证实） | 不应自动扩到 |
| --- | --- | --- |
| line 内容/旁白知识 | 对应声音行、字幕、包含它的 shot、编辑时长计划 | 无关场景或整剧配音 |
| speaker/选定 voice ref | 该人物相关声音行/take 引用及同步剪辑；是否改字幕看实际标签 | 其他角色声音或全部视觉 |
| 角色/道具视觉身份 | 引用旧设计的 shot/frame；若状态因果变了再追剧本/调度 | 没引用该资产的镜头 |
| 持物手/动作接点 | 当前 shot、前后直接相接 shot 及相关剪辑 | 全集每个镜头或无关尾镜 |

先记录确定已经过期的旧评审绑定，再另列建议采纳后才受影响的产物。没有新媒体时只能提“对应已生成产物若存在需复核”，不得虚构 take 或重生任务。旧审批记录不删除、不覆盖；提出新候选和重新评审条件。

## 阶段判定

| 目标阶段 | 可支持的结论 | 不能据此证明 |
| --- | --- | --- |
| 剧本/设计文稿 | 所给正典、知识/状态、选定引用在本 scope 是否自洽 | 注册完成、图像身份稳定、声音已试听 |
| 分镜/声音/剪辑计划 | 所检 line/shot/ref 覆盖与计划状态是否相容；可作 provisional 下一步输入 | 实际时长、画面质量、口型、混音/字幕精准 |
| 指定媒体连续性 | 已查看/试听区间与给定参考的具体连续性结论 | 未检查镜头/集数的质量、代码测试、自动发布批准 |

请求的是文稿评审时，媒体不存在不会单独阻断文稿结论；请求成片终检而媒体缺失则该阶段 `blocked`。发现必须修的事实冲突用 `revise`；缺证据用 `blocked`，不能把二者混成“内容肯定错误”。偏好项列 non_blocking_suggestions，不自设分数阈值追求满分。
