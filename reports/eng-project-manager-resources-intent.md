用户补充：管理哪些任务分配给哪些 agent/session、每个的产出资产和预算，并明确每个 goal 拆解后的 DAG 目标。

- 基线：cd990aaec765fcbd1731af970233484377c873aa，已验收 0.1.0；当前 worktree 在 codex/eng-project-manager-resources，原作者候选分支保持不变。
- 唯一 writer：当前任务；不新建任务、subagent、项目、仓库，不修改其他 skills 或公共契约，不自行合并 main。
- 输入消费者：主 agent 的任务与分配交接、实际 agent/session ID、已承诺产物、预算和使用量来源。数据未知用 null/未记录，不推断原生用量，不自动分派/调度/调整预算。
- 输出消费者：用户和主 agent。新增工作包目标/完成标准、分配沿革、实际交付记录、预算上限/已用/剩余/超支、按任务和 agent/session 查询、每 goal 的 DAG 目标表。
- 兼容性：0.1.0 → 0.2.0 MINOR；v1 snapshot/ledger 不变，新增可选 work_package/management 及只读查询输出。旧台账缺管理字段时明确未记录，原证据和产品完成语义不变。
- 有界验收：沿用三个代表场景，扩充正常分配/转交与去重汇总、未知/过期用量及缺资产、跨目标引用/预算篡改/计量回退拒绝；保留旧版三个场景的断言。最多三条顶层检查命令、一次验收、最多两次定向修正。不跑其他 skills 的行为回归。
- 非目标：估时平台、自动预算计费、货币换算、资源调度、后台轮询、跨 repo 联邦、自动签署原生 goal。
- 交付边界：留有证据的本地候选；新一轮独立验收未经授权不能自动派生 agent，也不能复用 0.1.0 的签字给 0.2.0 放行。已安装入口仍指向 main 的已验收版本，不能静默替换为未验收候选。
